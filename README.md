# TF Vocal Studio

ঘরে বসে কারাওকের সাথে গান গাওয়া ও রেকর্ড করার জন্য উইন্ডোজ সফটওয়্যার।

## ডাউনলোড ও ইনস্টল

1. এই পেজের ডান পাশে **Releases** অংশে যান।
2. সবচেয়ে নতুন রিলিজ থেকে **TF-Vocal-Studio-Setup-….exe** ফাইলটি ডাউনলোড করুন।
3. ফাইলটিতে ডাবল-ক্লিক করুন। নীল রঙের "Windows protected your PC" দেখালে **More info** চাপুন, তারপর **Run anyway** চাপুন।
4. **Next → Install** চাপুন। ডেস্কটপে **TF Vocal Studio** আইকন তৈরি হবে।

## যা যা আছে

- **শুরুর পর্দায় ৪টি বড় বোতাম** — অডিও/মিউজিক দিন · লিরিক্স ভিডিও দিন · লিরিক্স লিখুন/পেস্ট করুন · মিউজিক ছাড়াই গান করুন। যেকোনো ফাইল টেনে এনেও ছাড়া যায়
- **পরিষ্কার, ভাঙাহীন রেকর্ডিং** — USB মাইক আর স্পিকার আলাদা সাউন্ড কার্ডে থাকলেও কণ্ঠে "ক্যাট ক্যাট" আওয়াজ হয় না; রেকর্ডিং সবসময় আসল কণ্ঠ রাখে (৩২-বিট)
- **মোলায়েম ইফেক্ট** — স্টুডিও মানের অটো-টিউন (ফরম্যান্ট ঠিক রেখে), মসৃণ হলঘরের রিভার্ব, অটো লেভেল (আস্তে-জোরে গাওয়া সমান করে), উষ্ণতা, ডি-এসার, ইকো, ডাবল ভয়েস
- **২২টি কণ্ঠের প্রিসেট** — গান, ব্যান্ড, ধর্মীয়, কথা; নিজের প্রিসেট সেভ করুন
- **স্মার্ট মিক্স** — গাওয়ার সময় মিউজিক একটু সরে জায়গা দেয়; এক চাপে কণ্ঠ-মিউজিক ব্যালান্স; মাস্টার গ্লু ও লিমিটার
- **এক ক্লিকে পরিষ্কার** — নয়েজ সরান (ফ্যান/এসি/হিস), স্পিকার থেকে মাইকে ঢোকা মিউজিক সরান; Ctrl+Z দিলে আগের মতো
- **টাইমলাইন এডিটিং** — টুকরো ক্লিক করে Delete, প্রতিটা টুকরোর কোণে ×, কিনারা টেনে ছোট করা, কাঁচির দাগে দুই ভাগ (S), টেনে সরানো, রাইট-ক্লিকে সব অপশন, ভুল অংশ আবার গাওয়া, আগের টেক বেছে নেওয়া, জুম স্লাইডার, টাইমলাইন উঁচু-নিচু করা
- **রেকর্ডিংয়ের সাহায্য** — ৩-২-১ গণনা, বড় মাইক লেভেল বার (কম/ঠিক/বেশি), গাওয়ার সুর দেখায় (সরগমসহ), সিঙ্ক নিজে থেকে মাপা
- **মিউজিক** — গতি ৫০–১৫০% (সুর একই), সুর উঁচু/নিচু (গতি একই), গানের স্কেল নিজে থেকে ধরে
- **লিরিক্স** — স্ক্রল করা কারাওকে লিরিক্স; গান বাজিয়ে প্রতিটা লাইনে এক চাপ দিয়ে সময় মেলানো (Enter)
- **ক্যামেরা** — ওয়েবক্যাম বা USB-তে ফোন (DroidCam/Iriun) দিয়ে আপনাদের ভিডিও, নিচে লিরিক্স
- **সেভ / এক্সপোর্ট** — "কোথায় সেভ করবেন" জানালা; ভিডিও MP4 আড়াআড়ি (YouTube/Facebook) ও খাড়া ৯:১৬ (Reels/Shorts); পুরো গান, শুধু কণ্ঠ, শুধু মিউজিক, দুটো আলাদা ফাইল, WAV; ফেড-ইন/আউট; সোশ্যাল মিডিয়ার জোর (−১৪ LUFS)
- **সফটওয়্যারের ভেতর থেকেই আপডেট** — নতুন সংস্করণ এলে উপরে "আপডেট" বোতাম; ডাউনলোড নিরাপত্তা-পরীক্ষা (SHA-256) করে তবেই ইনস্টল
- **প্রজেক্ট নিজে থেকে সেভ হয়** — লাইব্রেরির "আমার প্রজেক্ট" থেকে আবার খুলুন

সব ফাইল থাকে: `Documents\TF Vocal Studio\` (Songs, Projects, Recordings, Exports)

**কীবোর্ড:** Space = চালান/বিরতি · R = রেকর্ড · L = লাইভ মাইক · S = দাগের জায়গায় কাটুন · Home = শুরুতে · Delete = বাছাই করা অংশ/টুকরো মুছুন · Ctrl+Z / Ctrl+Y = আগের অবস্থা / আবার · Ctrl+L = লুপ · Ctrl+O = ফাইল খুলুন · Enter = (লিরিক্স ট্যাপ করার সময়) লাইন শুরু

**আসল গান থেকে কারাওকে:** ফ্রি "Ultimate Vocal Remover (UVR)" সফটওয়্যারে RoFormer মডেল দিয়ে মিউজিক আলাদা করে এখানে দিন — সবচেয়ে পরিষ্কার ফল।

## ডেভেলপারদের জন্য

C++20, JUCE 9, CMake। প্রতিটি push-এ GitHub Actions উইন্ডোজে বিল্ড করে, স্বয়ংক্রিয় টেস্ট চালায় (স্যাম্পল-নির্ভুল সিঙ্ক, আলাদা ঘড়ির মাইকে ফাঁকা না পড়া, কণ্ঠের মান — রুক্ষতা/অ্যালিয়াসিং মাপা, নয়েজ ও মিউজিক-লিক সরানো, লাউডনেস, প্রতিটা বোতাম, এক্সপোর্ট, CPU লোড); সব পাস করলে তবেই Inno Setup দিয়ে Setup.exe ও তার SHA-256 বানায়।

```
cmake -S . -B build -A x64 -DTF_BUILD_TESTS=ON
cmake --build build --config Release
```

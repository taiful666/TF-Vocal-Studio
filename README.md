# TF Vocal Studio

ঘরে বসে কারাওকের সাথে গান গাওয়া ও রেকর্ড করার জন্য উইন্ডোজ সফটওয়্যার।

## ডাউনলোড ও ইনস্টল

1. এই পেজের ডান পাশে **Releases** অংশে যান।
2. সবচেয়ে নতুন রিলিজ থেকে **TF-Vocal-Studio-Setup-….exe** ফাইলটি ডাউনলোড করুন।
3. ফাইলটিতে ডাবল-ক্লিক করুন। নীল রঙের "Windows protected your PC" দেখালে **More info** চাপুন, তারপর **Run anyway** চাপুন।
4. **Next → Install** চাপুন। ডেস্কটপে **TF Vocal Studio** আইকন তৈরি হবে।

## যা যা আছে

- **লাইভ মাইক বাটন** (উপরে ডানে, কীবোর্ডে L) — চালু করলে তবেই কণ্ঠ স্পিকারে যায়; শুরুতে বন্ধ থাকে
- **২২টি কণ্ঠের প্রিসেট** — গান (গজল, রোমান্টিক, রবীন্দ্র/নজরুল, লোকগীতি…), ব্যান্ড (ভরাট গলা, হার্ড রক…), ধর্মীয় (হামদ-নাত, ওয়াজ, তিলাওয়াত), কথা (বক্তৃতা, আবৃত্তি, রেডিও); নিজের প্রিসেট সেভ; আগে/পরে তুলনা
- **ইফেক্ট** — অটো-টিউন (গানের স্কেল নিজে থেকে ধরে), কণ্ঠের রং (EQ), ভরাট গলা, রিভার্ব, ইকো, ডাবল ভয়েস, স-শ এর হিস কমানো — তীর-চিহ্নে চাপলে খোলে
- **রেকর্ডিংয়ের পরেও প্রিসেট বদলানো যায়** — কণ্ঠ আলাদা রেকর্ড হয়, ইফেক্ট শোনার ও সেভের সময় বসে
- **যেকোনো অডিও বা ভিডিও** — MP3, WAV, M4A, MP4, MKV, WEBM… লিরিক্স-ভিডিও দিলে তার আওয়াজ মিউজিক হয়, আর ভিডিও লিরিক্সের জায়গায় গানের সাথে মিলিয়ে চলে
- **লিরিক্স লিখুন/পেস্ট করুন** — লেখা ছোট-বড়, মাউস দিয়ে উপর-নিচ, স্ক্রলের গতি কমানো-বাড়ানো; সময়সহ .lrc দিলে কারাওকের মতো সোনালি হয়
- **AI দিয়ে কারাওকে** — যেকোনো গান থেকে কণ্ঠ আর মিউজিক আলাদা (ইন্টারনেট লাগে না)
- **AI নয়েজ রিমুভ** — ফ্যান, গাড়ি, গুঞ্জন বাদ (ইন্টারনেট লাগে না)
- **নিখুঁত সিঙ্ক** — রেকর্ডিং আর গান স্যাম্পল পর্যন্ত মিলিয়ে রাখা হয়
- **মিক্স সেভ** — গান আর ইফেক্টসহ কণ্ঠ মিলিয়ে WAV

সব ফাইল থাকে: `Documents\TF Vocal Studio\` (Songs, Recordings, Separated)

**কীবোর্ড:** Space = চালান/বিরতি, R = রেকর্ড, L = লাইভ মাইক, Home = শুরুতে যান, Ctrl+O = ফাইল খুলুন

## পরের ধাপগুলো

- ক্যামেরা + লিরিক্সসহ ভিডিও রেকর্ড, MP4 এক্সপোর্ট (আড়াআড়ি, খাড়া, বর্গ)
- লাইভ মোড স্ক্রিন, লিরিক্সে সময় মেলানোর এডিটর

## ডেভেলপারদের জন্য

C++20, JUCE 9, CMake। প্রতিটি push-এ GitHub Actions উইন্ডোজে বিল্ড করে, স্বয়ংক্রিয় ইঞ্জিন টেস্ট চালায় (স্যাম্পল-নির্ভুল সিঙ্ক, নয়েজ রিমুভ, এক্সপোর্ট, CPU লোড), তারপর Inno Setup দিয়ে Setup.exe বানায়। `v*` ট্যাগ push করলে Release তৈরি হয়।

```
cmake -S . -B build -A x64 -DTF_BUILD_TESTS=ON
cmake --build build --config Release
```

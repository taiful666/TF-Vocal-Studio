# TF Vocal Studio

ঘরে বসে কারাওকের সাথে গান গাওয়া ও রেকর্ড করার জন্য উইন্ডোজ সফটওয়্যার।

## ডাউনলোড ও ইনস্টল

1. এই পেজের ডান পাশে **Releases** অংশে যান।
2. সবচেয়ে নতুন রিলিজ থেকে **TF-Vocal-Studio-Setup-….exe** ফাইলটি ডাউনলোড করুন।
3. ফাইলটিতে ডাবল-ক্লিক করুন। নীল রঙের "Windows protected your PC" দেখালে **More info** চাপুন, তারপর **Run anyway** চাপুন।
4. **Next → Install** চাপুন। ডেস্কটপে **TF Vocal Studio** আইকন তৈরি হবে।

## এই সংস্করণে যা আছে (ধাপ ১)

- **খুব কম দেরির মনিটরিং** — মাইকে গাওয়ার সাথে সাথে স্পিকারে শোনা যায় (Windows Audio Low Latency / Exclusive মোড)
- **কারাওকে** — MP3, WAV, M4A, FLAC, OGG চলে; গানের পাশে একই নামের `.lrc` ফাইল থাকলে লিরিক্স নিজে থেকে স্ক্রল হয় আর গাওয়া অংশ সোনালি হয়
- **রেকর্ডিং** — কণ্ঠ আর গান স্যাম্পল পর্যন্ত মিলিয়ে রেকর্ড হয় (দেরি নিজে থেকে ঠিক করা হয়); প্রতিটি রেকর্ডিং আলাদা ফোল্ডারে সেভ হয়
- **AI নয়েজ রিমুভ** — ফ্যান, গাড়ি, ঘরের গুঞ্জন বাদ দেয়, ইন্টারনেট লাগে না
- **শেষ রেকর্ডিং শুনুন** — গানের সাথে মিলিয়ে নিজের রেকর্ডিং শুনুন
- **মিক্স সেভ** — গান আর কণ্ঠ মিলিয়ে একটি WAV ফাইল
- **গানের লাইব্রেরি** — গান যোগ করা, খোঁজা, মুছে ফেলা (রিসাইকেল বিনে যায়)

সব ফাইল থাকে: `Documents\TF Vocal Studio\` (Songs, Recordings)

**কীবোর্ড:** Space = চালান/বিরতি, R = রেকর্ড, Home = শুরুতে যান, Ctrl+O = ফাইল খুলুন

## পরের ধাপগুলো

2. সুর ঠিক করা (অটো-টিউন), ২২টি কণ্ঠের প্রিসেট (গজল, ব্যান্ড রক, ওয়াজ, আবৃত্তি…), রিভার্ব/ইকো, লাইভ মোড
3. ক্যামেরা + লিরিক্সসহ ভিডিও, MP4 এক্সপোর্ট (আড়াআড়ি, খাড়া, বর্গ)
4. আসল গান থেকে AI দিয়ে মিউজিক আলাদা করা, লিরিক্স এডিটর
5. চূড়ান্ত ডিজাইন পলিশ

## ডেভেলপারদের জন্য

C++20, JUCE 9, CMake। প্রতিটি push-এ GitHub Actions উইন্ডোজে বিল্ড করে, স্বয়ংক্রিয় ইঞ্জিন টেস্ট চালায় (স্যাম্পল-নির্ভুল সিঙ্ক, নয়েজ রিমুভ, এক্সপোর্ট, CPU লোড), তারপর Inno Setup দিয়ে Setup.exe বানায়। `v*` ট্যাগ push করলে Release তৈরি হয়।

```
cmake -S . -B build -A x64 -DTF_BUILD_TESTS=ON
cmake --build build --config Release
```

# TF Vocal Studio

ঘরে বসে কারাওকের সাথে গান গাওয়া ও রেকর্ড করার জন্য উইন্ডোজ সফটওয়্যার।

## ডাউনলোড ও ইনস্টল

1. এই পেজের ডান পাশে **Releases** অংশে যান।
2. সবচেয়ে নতুন রিলিজ থেকে **TF-Vocal-Studio-Setup-….exe** ফাইলটি ডাউনলোড করুন।
3. ফাইলটিতে ডাবল-ক্লিক করুন। নীল রঙের "Windows protected your PC" দেখালে **More info** চাপুন, তারপর **Run anyway** চাপুন।
4. **Next → Install** চাপুন। ডেস্কটপে **TF Vocal Studio** আইকন তৈরি হবে।

## যা যা আছে

- **শুরুর পর্দায় ৪টি বড় বোতাম** — অডিও/মিউজিক দিন · লিরিক্স ভিডিও দিন · লিরিক্স লিখুন/পেস্ট করুন · মিউজিক ছাড়াই গান করুন। যেকোনো ফাইল টেনে এনেও ছাড়া যায়
- **লেয়ার (ট্র্যাক)** — উপরে মিউজিক, নিচে কণ্ঠ। প্রতিটি লেয়ারে আলাদা ভলিউম, মিউট, শুধু-এটা-শুনুন (S), প্যান। যত খুশি কণ্ঠ লেয়ার (যেমন মেয়ের জন্য আলাদা)
- **রেকর্ডের পর চালান চাপলেই মিউজিক আর আপনার কণ্ঠ একসাথে বাজে** — ইফেক্টসহ, স্যাম্পল পর্যন্ত মিলিয়ে
- **ভুল অংশ আবার গাওয়া** — টাইমলাইনে টেনে অংশ বাছুন → "এই অংশ আবার গাই"। আগে ২ সেকেন্ড শোনায়, শুধু ওই অংশটুকু বদলায়
- **কাটা, সরানো, লুপ, আগের অবস্থা (Ctrl+Z)** — অংশ কেটে ফেলা, কণ্ঠ আগে-পিছে সরানো, একটা অংশ বারবার বাজিয়ে অনুশীলন
- **মিউজিকের গতি** — ৫০% থেকে ১৫০%, সুর (স্কেল) একই থাকে
- **ডান পাশে গোছানো সেটিংস** — বাছাই করা লেয়ারের সব কিছু: প্রিসেট (ক্যাটাগরি অনুযায়ী), ইফেক্ট চেইন (প্রতিটি খুললে নব), মাইক ও AI নয়েজ রিমুভ; মিউজিক লেয়ারে গতি, স্কেল, AI দিয়ে আসল কণ্ঠ সরানো
- **২২টি কণ্ঠের প্রিসেট** — গান, ব্যান্ড (জেমস/আইয়ুব বাচ্চুর মতো ভরাট গলা), ধর্মীয় (হামদ-নাত, ওয়াজ, তিলাওয়াত), কথা (বক্তৃতা, আবৃত্তি); নিজের প্রিসেট সেভ/মুছুন; আগে/পরে তুলনা
- **যেকোনো অডিও বা ভিডিও** — MP3, WAV, M4A, MP4, MKV, WEBM…; লিরিক্স-ভিডিওর ছবি গানের সাথে মিলিয়ে চলে
- **AI নয়েজ রিমুভ ও AI কারাওকে** — ইন্টারনেট ছাড়াই
- **প্রজেক্ট নিজে থেকে সেভ হয়** — লাইব্রেরির "আমার প্রজেক্ট" থেকে আবার খুলুন
- **সেভ / এক্সপোর্ট** — MP3 (ফেসবুক/ইউটিউবের জন্য) বা WAV; পুরোটা বা শুধু বাছাই করা অংশ
- **অডিও সেটিংস** — ডিভাইস · রেকর্ডিং ও সিঙ্ক · পরীক্ষা (সব ঠিক আছে কিনা সবুজ/হলুদ দেখায়)

সব ফাইল থাকে: `Documents\TF Vocal Studio\` (Songs, Projects, Recordings, Exports)

**কীবোর্ড:** Space = চালান/বিরতি · R = রেকর্ড · L = লাইভ মাইক · Home = শুরুতে · Delete = বাছাই করা অংশ কাটুন · Ctrl+Z / Ctrl+Y = আগের অবস্থা / আবার · Ctrl+L = লুপ · Ctrl+O = ফাইল খুলুন

## পরের ধাপগুলো

- ক্যামেরা + লিরিক্সসহ ভিডিও রেকর্ড, MP4 এক্সপোর্ট (আড়াআড়ি, খাড়া, বর্গ)
- লাইভ মোড স্ক্রিন, লিরিক্সে সময় মেলানোর এডিটর

## ডেভেলপারদের জন্য

C++20, JUCE 9, CMake। প্রতিটি push-এ GitHub Actions উইন্ডোজে বিল্ড করে, স্বয়ংক্রিয় ইঞ্জিন টেস্ট চালায় (স্যাম্পল-নির্ভুল সিঙ্ক, নয়েজ রিমুভ, এক্সপোর্ট, CPU লোড), তারপর Inno Setup দিয়ে Setup.exe বানায়। `v*` ট্যাগ push করলে Release তৈরি হয়।

```
cmake -S . -B build -A x64 -DTF_BUILD_TESTS=ON
cmake --build build --config Release
```
